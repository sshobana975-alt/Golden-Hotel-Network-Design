# Golden Hotel Network Design

## 📌 Project Overview
This project presents a network design for **Golden Hotel** using **Cisco Packet Tracer**. The network was designed to provide reliable and secure communication between different areas and departments of the hotel.

## 🎯 Project Objectives
- Design a structured hotel network.
- Connect different departments and network devices.
- Configure IP addressing and network connectivity.
- Apply routing and switching concepts.
- Test and troubleshoot network communication.

## 🛠️ Technologies & Tools
- Cisco Packet Tracer
- Cisco Routers
- Cisco Switches
- TCP/IP
- IP Addressing
- Routing and Switching

## 🌐 Network Design
The network topology was designed and configured in Cisco Packet Tracer. Different network devices were connected and configured to provide communication across the hotel network.
